# Policy-care
PolicyCare is a modern healthcare management web application designed to make hospital admission, insurance information, and care services easier to access. The project provides a simple and user-friendly interface where users can explore healthcare services and get important information in one place.
🎯 Main Objectives

The main objectives of PolicyCare are:

Provide healthcare information in one place.
Make hospital information easy to understand.
Display hospital bed and ICU availability.
Provide sample insurance and healthcare scheme information.
Assist users with the hospital admission process.
Provide home nursing and prescription delivery options.
Provide an interactive chatbot for website navigation.
Create a simple and responsive healthcare interface.
Demonstrate how web technologies can be used in healthcare applications.
🏥 Hospital Information

The Hospitals section displays sample hospital information including:

Hospital name
Medical specialty
ICU bed availability
Total beds
Hospital operational status

Users can view the available hospital information through interactive hospital cards.

The dashboard also contains a network occupancy chart that visually represents sample hospital occupancy data.

📝 Admission Assistance

PolicyCare includes an Admission section where users can provide information such as:

Full name
Medical specialty
Urgency level
Insurance information
Preferred hospital

The application then demonstrates an admission feasibility result based on the available sample hospital information.

This feature is created for demonstration purposes and does not represent a real medical admission or clinical decision system.

🛡️ Insurance Information

The Insurance section displays sample insurance and healthcare schemes.

The information includes:

Policy or scheme name
Type of coverage
Coverage percentage
Annual coverage limit

This section is designed to help users understand how insurance information can be presented in a simple and organized way.

🏠 Care Continuity

PolicyCare also provides healthcare support services after hospital-related activities.

The Care Continuity section includes:

👩‍⚕️ Home Nursing

Users can request skilled home nursing services through a simple form.

💊 Prescription Delivery

Users can submit prescription delivery information and request medicine delivery through the application interface.

These features are included as demonstrations of healthcare support services.

🤖 AI Assistant

PolicyCare contains an interactive AI Assistant-style chatbot that helps users navigate the website.

The assistant can respond to common keywords and guide users toward sections such as:

Hospitals
Admission
Insurance
Care services
Contact information

The chatbot also supports browser-based voice input and text-to-speech functionality where supported by the browser.

The current chatbot is a demonstration feature using predefined keyword-based responses. It is not connected to an external AI service or real healthcare database.

🚨 Emergency SOS

The application includes an SOS Emergency button designed to demonstrate how an emergency assistance interface could work.

When activated, the application displays an emergency response message and location-related status.

This is only a UI simulation. It does not actually contact emergency services, hospitals, ambulance services, or transmit a user's real location.

📊 Dashboard & Data Visualization

The PolicyCare dashboard uses an interactive chart to display sample hospital network occupancy information.

Chart.js is used to create the visualization, making the dashboard more interactive and easier to understand.

⚠️ Disclaimer

PolicyCare is a student/demo project created to demonstrate healthcare-related web application concepts.

The hospital information, insurance plans, occupancy values, admission scores, emergency SOS responses, and healthcare services shown in the application are demonstration data and functionality.

The application should not be used for real medical decisions, emergency communication, hospital admission, insurance claims, or healthcare treatment.
